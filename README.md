# Гражданская оборона

Программа для учёта данных гражданской обороны в организации.
Работает в браузере. Позволяет загружать файлы, обрабатывать их
и получать готовые отчёты в Excel.

## Возможности

- Загрузка файлов CSV, XLSX, JSON.
- Автоопределение типа файла (кадры, СИЗ, обучение, формирования).
- Очистка данных от дубликатов и ошибок.
- Просмотр загруженных данных в виде таблиц.
- Отчёт по формированиям.
- План освежения СИЗ на 5 лет вперёд.
- Сохранение данных в базе — не теряются при перезапуске.

## Установка

### Что нужно

- Python 3.10 или новее.
- pip.

### Шаги

1. Скачать проект:

   ```bash
   git clone https://github.com/nonetgit/go-module.git
   cd go-module
   ```

   Если Git не установлен — на странице репозитория нажмите
   **Code → Download ZIP** и распакуйте архив.

2. Установить зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. Запустить:

   ```bash
   python app.py
   ```

4. Открыть в браузере: <http://localhost:5000>

## Как пользоваться

Программа состоит из четырёх разделов. Они в верхнем меню.

### Раздел 1. Загрузка данных

Здесь загружаются файлы с компьютера.

1. Нажмите на серую область «Файлы для загрузки».
2. В открывшемся окне выберите нужные файлы.
   Чтобы выбрать сразу несколько — зажмите **Ctrl** и кликайте по файлам,
   или нажмите **Ctrl+A** для выбора всех файлов в папке.
3. Нажмите кнопку «Обработать файлы».

После обработки:

- Вверху появятся счётчики — сколько сотрудников, СИЗ,
  участников формирований и записей обучения загружено.
- Внизу появится журнал обработки — что произошло с каждым файлом.

### Раздел 2. Загруженные данные

Здесь видно, что именно попало в программу. Четыре вкладки:

- **Сотрудники** — табельный номер, ФИО, подразделение, должность.
- **СИЗ** — код, наименование, партия, количество, срок годности.
- **Формирования** — кто в каком формировании и в какой роли.
- **Обучение** — кто какую тему прошёл и с каким результатом.

Если что-то не так — вернитесь в «Загрузка данных» и загрузите
исправленные файлы.

### Раздел 3. Отчёт по формированиям

Готовый отчёт, формируется автоматически после загрузки файлов.

Что внутри:

- Состав формирований — список и количество человек.
- Обеспеченность СИЗ — сколько нужно, сколько есть, сколько годных.
- Подготовка сотрудников — сколько человек прошло обучение.

Кнопка «Скачать отчёт в Excel» — сохраняет отчёт на компьютер.

### Раздел 4. План освежения СИЗ

Готовый план закупок на 5 лет вперёд. Программа сама смотрит
сроки годности партий и рассчитывает, когда и что закупать.

Кнопка «Скачать план в Excel» — сохраняет план на компьютер.

### Кнопка «Сбросить данные»

Находится на главной странице. Удаляет всё, что было загружено.

## Форматы файлов

### Поддерживаемые форматы

- **Excel** — файлы `.xlsx`
- **CSV** — файлы `.csv` (разделитель запятая или точка с запятой,
  определится автоматически)
- **JSON** — файлы `.json` (массив объектов)
